# ISSO_Tools

Tools and guides for Information System Security Officers.

| Tool | Description |
|---|---|
| [STIG Explorer](STIG_Explorer/) | Searchable database and web app for 14 DISA STIGs (RHEL 7–10, Ubuntu 18.04–24.04 LTS, Windows 10/11, Windows Server 2016–2025 with domain controller views): 3,877 rules. For each rule it shows the exact settings changed and explains the rule at three levels (Cyber Security Professional, System Administrator, General Audience). It gives copy-and-paste PowerShell/CMD/Bash validation commands, exports read-only validation scripts, maps rules to NIST SP 800-53 Rev 3/4/5, and supports custom tags such as FMCC. It runs offline from an HTML file or in a hardened Docker container with a JSON API, and generates Word and Markdown guides. |
