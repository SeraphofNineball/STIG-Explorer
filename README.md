# ISSO_Tools

Tools and guides for Information System Security Officers.

| Tool | Description |
|---|---|
| [STIG_Explorer](STIG_Explorer/) | Searchable database and web app for the DISA RHEL, Ubuntu and Windows desktop/server STIGs (including domain controller views). It shows the exact settings each rule changes, explains every rule at three levels (Cyber Security Professional, System Administrator, General Audience), gives copy-and-paste validation commands and maps rules to NIST SP 800-53 Rev 3/4/5. It runs locally from an HTML file or in a Docker container, and generates Markdown and Word guides. |
